# 手機版面驗證

驗證日期：2026-09-23。

## 調整原因

舊版在 390px 視窗下，第一張圖表起點約在頁面 854px。部分手機 CSS 排在桌面樣式之前，導致卡片字級與尺寸被覆蓋；日期欄位與五張指標卡也占用過多直向空間。

## 實作

- 760px 以下採用手機排版：股票輸入與查詢並排、日期預設收合、兩欄指標卡與整列 Z-Score 區間。
- 價格、斜率、Z-Score 以頁籤切換；桌面維持三圖排列。
- 手機預設保留頁面上下捲動；按「操作圖表」後啟用圖表拖曳／縮放，按「完成操作」恢復。
- 表單字級為 16px，主要按鈕至少 44px 高；搜尋結果可透過按鈕點選。
- 查詢狀態顯示股票與資料日期；更新失敗時明確標示仍是上次結果。
- 日期區間在送出前驗證，新的行情請求會取消舊請求，避免較慢的舊結果蓋過新查詢。

## 已驗證

- Chromium 視窗 320px、390px、768px 與 1280px 的排版；320px 與 768px 的文件寬度未超出可見寬度。
- 日期展開、無效日期提示、NVDA／SPY 真實行情查詢。
- 三個圖表頁籤切換、圖表操作模式切換、跨手機／桌面斷點重新繪圖。
- 桌面仍顯示五張指標卡及三張圖表。
- 36 項 Python 測試通過，渲染後 JavaScript 通過 Node 語法檢查。

以上為桌面瀏覽器的尺寸模擬與操作檢查，未使用實體 iPhone／Android 驗證觸控與原生日期選擇器。
